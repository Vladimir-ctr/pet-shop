

### Отличие v1 от v2

- В v1 тесты используют ручной мок для интерфейса Products: в тестах создаётся собственная структура с функциями-обработчиками, например `GetAllProductsFunc`, `CreateProductFunc` и т.д.
- В v2 подход меняется: ручной мок убирается, а вместо него используется автоматически сгенерированный мок через `go:generate` и `mockery`.
- С точки зрения поведения тестов, логика остаётся прежней: те же сценарии успеха, ошибки и bad request, но способ создания мока становится автоматическим.
- То есть отличие между v1 и v2 не в бизнес-логике обработчиков, а в том, как организованы тесты и как создаются моки для интерфейса Products.

## 🧪 Запуск тестов

Для запуска всех тестов выполните:

```bash
go test ./...
```

Для запуска тестов только для пакета с обработчиками товаров:

```bash
go test ./internal/handlers/product
```

Для запуска конкретного теста:

```bash
go test ./internal/handlers/product -run ^TestCreateProduct_Success$
```
